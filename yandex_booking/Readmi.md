# Booking Service (Backend)

Сервис для управления бронированием мест, написанный на **Go** в рамках отбора на стажировку в Яндекс.

## Стек технологий
- **Язык**: Go (Golang)
- **База данных**: PostgreSQL
- **Библиотеки**: `net/http` (стандартная библиотека), `://github.com` (драйвер БД)
- **Инструменты**: Docker (для локального развертывания БД)

## Что было сделано
1. Реализован HTTP-сервис с тремя эндпоинтами:
   - `GET /ping`: Health-check сервиса.
   - `POST /book`: Создание бронирования с проверкой пересечений по времени.
   - `GET /booklist`: Получение списка бронирований для конкретного пользователя или места с сортировкой.
2. Настроено подключение к PostgreSQL через переменные окружения.
3. Оптимизирована работа с БД с использованием пула соединений (`SetMaxOpenConns`).

## С чем я столкнулся в процессе
В ходе разработки пришлось решить несколько интересных задач:
- **Логика пересечений**: Первоначально возникли сложности с условием наложения временных интервалов. В итоге была выведена оптимальная SQL-логика: `NOT (time_to <= new_from OR time_from >= new_to)`, которая учитывает полуинтервалы `[from, to)`.
- **Оптимизация производительности**: При нагрузочном тестировании сервис начал выдавать `Time Limit`. Проблема была решена добавлением индексов и оптимизацией SQL-запросов (использование `LIMIT 1` для проверки существования записи).
- **Специфика форматов**: Столкнулся с тем, что стандартный `time.RFC3339` в Go может добавлять наносекунды, что не всегда корректно воспринималось проверяющей системой. Перешел на строгий формат `2006-01-02T15:04:05Z`.

## Как запустить

1. **Запуск базы данных**:
   ```bash
   docker run --name pg-booking -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=contest -p 5432:5432 -d postgres
   ```

2. **Инициализация таблицы**:
   ```sql
   CREATE TABLE bookings (
       id SERIAL PRIMARY KEY,
       user_id INTEGER NOT NULL,
       place_id INTEGER NOT NULL,
       time_from TIMESTAMP NOT NULL,
       time_to TIMESTAMP NOT NULL
   );
   ```

3. **Запуск сервиса**:
   ```bash
   go build -o service .
   ./service --port 8080
   ```
