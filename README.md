# Yandex Works Solutions

Репозиторий содержит решения алгоритмических задач, выполненные на языках **C++** и **Python**. В проекте представлены задачи на динамическое программирование, работу с массивами и вероятностные алгоритмы.

## 📋 Описание выполненных заданий

### 1. Расчет очков в симуляторе прыжков (C++)
*   **Задача:** Моделирование движения по трассе с препятствиями. Необходимо рассчитать итоговый счет на основе массива препятствий и массива прыжков.
*   **Реализация:** 
    *   Используется структура `Prepyatstvie` для хранения границ и стоимости.
    *   Алгоритм проходит по трассе методом двух указателей, что обеспечивает линейную сложность **O(N + M)**.
    *   Обработка штрафов за пропущенные или задетые препятствия.

### 2. Генератор оптимальных деревьев поиска (Python)
*   **Задача:** Построение всех возможных бинарных деревьев поиска с минимальной стоимостью доступа.
*   **Реализация:**
    *   **DP (Динамическое программирование):** Заполнение таблицы стоимостей `dp[i][j]` за $O(N^3)$.
    *   **Префиксные суммы:** Для мгновенного вычисления суммы весов на отрезке.
    *   **Рекурсия:** Восстановление всех вариантов структуры дерева из сохраненных корней.

### 3. Поиск коллизий сумм подмножеств (C++ & Python)
*   **Задача:** Найти два непересекающихся подмножества элементов с одинаковой суммой (для набора из 40 чисел).
*   **Реализация:**
    *   **C++ (Оптимизированная версия):** Использует битовые маски и генератор `mt19937_64`. За счет низкой абстракции и эффективного хеширования работает максимально быстро.
    *   **Python (Прототип):** Использует `random.sample` и словари для поиска совпадений. Удобен для отладки логики.
    *   **Алгоритм:** Основан на парадоксе дней рождения — случайная генерация подмножеств быстро приводит к нахождению коллизии суммы.

## 🛠 Стек технологий
*   **C++:** Стандарт 17+, компилятор GCC/Clang.
*   **Python:** 3.8+ (без сторонних зависимостей).

## 🚀 Как запустить

### C++
```bash
g++ -O3 main.cpp -o solution
./solution < input.txt
```

### Python
```bash
python3 main.py < input.txt
```
